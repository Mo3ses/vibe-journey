# Diário de Vibe Coding

Minha jornada no [Vibe Coding 101 (easy-vibe)](https://github.com/datawhalechina/easy-vibe), do primeiro jogo ao produto de pé.

## Como funciona

- Uma sessão de estudo = um registro em `journal/AAAA-MM-DD-slug.md`.
- Uma sessão = um commit com a data no nome: `docs(jornada): 2026-10-26 - primeiro contato`.
- A linha do tempo é o `git log`. A tabela abaixo é só o índice.
- Cada registro responde a quatro perguntas: o que eu tentei, o que quebrou, como resolvi e o que eu faria diferente.

## Estrutura

| Caminho | O que tem |
|---|---|

| `AGENTS.md` | Rotina que cada nova sessão do agente segue |
