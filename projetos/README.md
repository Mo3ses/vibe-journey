## Como adicionar

1. Crie `projetos/<slug>/`.
2. Salve um `screenshot.png` ou `demo.gif`.
3. Escreva um `README.md` curto: o que é, como rodar e o que aprendi.
4. Linke a demo e o registro na tabela acima.
